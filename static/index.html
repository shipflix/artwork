Install on iPhone or iPad

New to Strand - Media Hub? Get Strand - Media Hub on the App Store, then follow these steps.

  1. Back up your current shelves. In Strand - Media Hub, open Settings → Shelves → Copy to Clipboard, then paste that backup into a note and save it before continuing.
  2. Choose your shelf categories above. Start with Recommended, then expand shelf categories to select just the folders you want. Check the folder count and import size before importing.
  3. Tap Copy selected shelves. Keep this page open in Safari and wait for the confirmation that your selected shelves have been copied. The optional Download JSON button saves the same selection as a JSON file if you want a file backup.
  4. Import in Strand - Media Hub. Open Settings → Shelves → Import from Clipboard. If iOS asks whether Strand - Media Hub can paste from Safari, allow it.
  5. Choose Append or Overwrite. Append adds the selected shelves to your existing shelves and can create duplicates if you import them again. Overwrite replaces your current shelf setup with this selection, so only choose it when you have a backup and want to replace those shelves.

These are browsing shelves and artwork. Keep your own metadata and playback services configured in Strand - Media Hub. For Apple TV, enable Strand - Media Hub’s iCloud sync on both devices using the same Apple Account and allow the shelves to sync.

About artwork updates

Shipflix generates fresh artwork daily at the same image URLs, so poster stacks and backgrounds reflect changes to the content in each collection. Logos and other curated artwork stay fixed.

Artwork does not currently refresh automatically in Strand - Media Hub. In the creator’s testing, reimporting the shelves picked up the new images. The shelves still work with the artwork already downloaded; reimporting is optional. Back up first: Append may create duplicates, while Overwrite removes all existing shelves.

We hope Strand will support automatic image refresh in a future update, but there is no confirmed release date. Support the image refresh feature request on Discord.
